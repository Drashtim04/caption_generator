# Contributing

Thanks for your interest in improving Caption Generator.

## Development setup

1. Install Flutter (3.9+)
2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run --dart-define=BACKEND_BASE_URL=https://your-api.com
```

## Code style

- Follow existing formatting and lint rules.
- Keep widgets small and focused.
- Prefer readable, explicit names.

## Pull requests

- Describe the problem and solution.
- Include screenshots for UI changes.
- Ensure `flutter analyze` passes.

## Reporting bugs

Open an issue with steps to reproduce, expected behavior, and screenshots.
